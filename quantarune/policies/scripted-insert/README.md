# scripted-insert

This folder holds the scripted insertion finish that closed the SC runs. The live file RunACTStagedScriptedInsert.py is version 5 and came from the ros/ folder of aic-quantarune. Version 4 is the same file run with the environment AIC_SCRIPTED_INSERT_RETRIES=4 and AIC_SCRIPTED_INSERT_TIME_S=30. The snapshots/ folder holds the frozen v3 and v4 copies from policy_snapshots/ in aic-quantarune. Versions 1 and 2 were not copied by user decision of 2026-10-31. The 35 legal full insertions on scene 004 used this scripted finish.
